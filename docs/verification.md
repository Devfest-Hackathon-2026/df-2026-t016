# 検証ページの表示と確認できる範囲

## 表示する情報

**制作記録**の見出しの下に「タイトル」「制作者」をラベル付きで出す。

**作者の申告**は、確定時に描き手が選んだ AI の使い方と任意の詳細を表示する。表示文は「作者が確定のときに選んだ申告です。運営とこのページは、申告の内容が本当かどうかを確かめていません。」とする。

受信区間は運営が記録を受け取った最初と最後の時刻をもとに表示する。「録画が続いた時間で、この絵の制作時間ではありません」と添える。

ブラウザは証拠一式の受領証、端末署名、ハッシュのつながり、件数と画像のハッシュを検証する。提出 PNG と終了画面の外観照合はサーバーで行う。手元の PNG のハッシュ照合はブラウザで行い、ファイルが確定時の提出 PNG と同じかを確かめる。

## 確認できないこと

- 手描きであること、AI を使ったかどうかとその程度
- 本人が操作したこと
- 制作の全体を収録したこと
- 記録の間ずっとこの絵を描いていたこと（途中で別の絵やアプリに切り替えていないかは分かりません）
- 本物のアプリから送られたこと（F8 を入れても、示せるのは「開始トークンを本物の本体アプリが受け取った」ことまで）
- 時刻と照合結果が正しいこと（これらは運営の記録で、運営を信頼する前提。証拠一式を受け取った後に書き換えられた場合は検出できる）

記録が2回以上のときは「記録と記録の間（録画していない間）のこと」も示す。F8 は Firebase App Check による記録開始時の確認を指す。

## 初版では見分けられない例

- 録画済みの制作動画を再生して録画した場合
- 下のレイヤーに置いた完成画像を、少しずつ見せていった場合
- 録画前に取り込んでおいた画像

## 途中の全体画像と AI の注意点

キャンバス全体が画面に映った瞬間を、記録の中で撮った画像です。時刻は、その画像を含む記録を運営が受け取った時刻です。隣どうしで、描かれた部分がそのまま残っているかを決まったルールで確かめ、前の画像で描かれていた部分のうち変わっていた割合を「◯%の変更」と出しています。

同じ絵を描き続けたことの証明ではありません。全体を表示しなかった間のことや、全体を表示するときだけ同じ絵に戻した場合は分かりません。

描き手が全体画像を非公開にしたときは「作者が途中の画像を公開しないことを選びました」と表示する。

Gemini は、同じ録画内で隣り合う公開の途中画像のうち、画像の差をもとに選んだ最大2組を比べる。渡すのはキャンバス部分を切り出した前後2枚、受信間隔、受信の空きがある場合はその最長の長さ。注意点がある場合は、対象の2枚の間に紫の目印を表示する。
